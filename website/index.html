功能

该有的都在一个程序里

从解压刷机包到分区扩容，不需要再另外准备工具和命令行。

刷机向导

选择 ROM、连接设备、核对计划、执行刷入并查看结果，左侧进度栏随时可以回到已完成的步骤。

完整线刷与保留数据更新

根据包内配置和脚本提供可用操作。更新脚本仍会改写用户数据时，不提供保留数据选项。

ROM 解压可续

读取 ZIP 或已解压目录，自动检查磁盘空间，复用已有结果，中途关闭后从断点继续。

独立工具

刷入 ID 补丁、Root 镜像（Magisk / KernelSU / APatch），以及配置启用的 Super 扩容与恢复。

开箱即用

内嵌 adb 与 fastboot；检测到手机已连接但缺少 Android USB 驱动时，可一键安装。

完整日志

记录设备命令、处理阶段和分区转换进度，遇到问题一键复制，或直接打开日志文件夹。

安全

写入之前，先检查一遍

刷机出错的代价很高。工具在每个关键节点都会停下来核对，不确定的事情一律拒绝执行。

  • ✓
    机型匹配

    设备代号与刷机包不符时无法继续。

  • ✓
    Super 容量预检

    容量不足时提示扩容，手机不会被写入任何内容。

  • ✓
    防回滚检查

    拒绝刷入防回滚版本更低的系统，避免无法开机。

  • ✓
    确认词

    完整线刷会清空数据，开始前需要输入 WIPE。

  • ✓
    不锁 Bootloader

    拒绝执行任何锁定 Bootloader 的命令。

  • ✓
    扩容先备份

    先备份 GPT，校验通过后才修改分区；恢复时核对磁盘与机型。

刷机包

两种包格式，同一套流程

工具解析受支持的配置与脚本语句，不直接运行 BAT。未知语句、包外路径和锁定命令会导致处理失败。

flash_profile.toml

FlashProfile 刷机包

程序查找 META-INF/com/android/flash_profile.toml，据此确定设备匹配、镜像映射、操作选项与所需工具。

ROM/
├── META-INF/com/android/flash_profile.toml
├── images/
└── tools/
flash_all.bat

小米官方线刷包

选择包含 flash_all.bat 和 images/ 的已解压目录，执行机型与防回滚检查、条件分支和刷写操作。

shennong_images_OS2.0…/
├── flash_all.bat                  完整线刷
├── flash_all_except_storage.bat   保留数据
├── misc.txt
└── images/

完整线刷会清除数据。使用前请解锁 Bootloader、备份资料，并确认刷机包支持当前机型。

运行要求

  • Windows 10 或更高版本
  • WebView2 Runtime（Windows 11 已内置）
  • 已解锁 Bootloader 的 Android 手机
  • 质量可靠的 USB 数据线

从源码构建

git clone https://github.com/wwrrj/WrionFlashTool.git
cd WrionFlashTool
pnpm --dir frontend install --frozen-lockfile
cargo install tauri-cli --version '^2' --locked
./build.ps1

需要 Rust stable（MSVC）、Visual Studio 2022 Build Tools、Node.js 与 pnpm。
