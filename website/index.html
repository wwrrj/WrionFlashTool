功能

不用再翻教程敲 fastboot 命令

从解压刷机包到分区扩容，不需要再另外准备工具和命令行。

刷机向导

选择 ROM、连接设备、核对计划、执行刷入并查看结果，左侧进度栏随时可以回到已完成的步骤。

完整线刷与保留数据更新

按刷机包里的配置和脚本给出能用的刷入方式。如果“保留数据”的脚本其实还会清除用户数据，这个选项就不会出现。

ROM 解压可续

读取 ZIP 或已解压目录，自动检查磁盘空间，复用已有结果，中途关闭后从断点继续。

独立工具

刷入 ID 补丁、Root 镜像（Magisk / KernelSU / APatch），以及配置启用的 Super 扩容与恢复。

开箱即用

内嵌 adb 与 fastboot；检测到手机已连接但缺少 Android USB 驱动时，可一键安装。

完整日志

记录设备命令、处理阶段和分区转换进度，遇到问题一键复制，或直接打开日志文件夹。

安全

写入之前，先检查一遍

刷机出错的代价很高。工具在每个关键节点都会停下来核对，不确定的事情一律拒绝执行。

  • ✓
    机型匹配

    设备代号与刷机包不符时无法继续。

  • ✓
    Super 容量预检

    容量不足时提示扩容，手机不会被写入任何内容。

  • ✓
    防回滚检查

    拒绝刷入防回滚版本更低的系统，避免无法开机。

  • ✓
    确认词

    完整线刷会清空数据，开始前需要输入 WIPE。

  • ✓
    不锁 Bootloader

    拒绝执行任何锁定 Bootloader 的命令。

  • ✓
    扩容先备份

    先备份 GPT，校验通过后才修改分区；恢复时核对磁盘与机型。

刷机包

两种包格式，同一套流程

目前主要面向小米机型：小米官方线刷包可以直接使用；FlashProfile 刷机包需要针对机型单独适配。工具只解析受支持的配置与脚本语句，不直接运行 BAT，遇到未知语句、包外路径或锁定命令会直接拒绝。

flash_profile.toml

FlashProfile 刷机包

程序查找 META-INF/com/android/flash_profile.toml，据此确定设备匹配、镜像映射、操作选项与所需工具。

ROM/
├── META-INF/com/android/flash_profile.toml
├── images/
└── tools/
flash_all.bat

小米官方线刷包

选择包含 flash_all.bat 和 images/ 的已解压目录，执行机型与防回滚检查、条件分支和刷写操作。

常见问题

刷机时最常遇到的几件事

没找到答案的话，带上日志到 GitHub 提问题。日志可以在软件里一键复制，提交前删掉序列号等个人信息。

Windows 提示“已保护你的电脑”，能运行吗？

程序目前没有代码签名，第一次运行时 SmartScreen 可能会拦截，这是正常现象。确认文件来自本站且校验值一致后，点“更多信息”→“仍要运行”。校验值见下方下载区。

插上手机了，但一直找不到设备？

先换原装或质量好的数据线，直接插电脑机箱后面的 USB 口，不要用扩展坞。手机保持亮屏开机，或进入 Fastboot（小米：关机后同时按住音量下和电源键）。如果页面提示缺少 USB 驱动，点“一键安装驱动”，装好后重新插拔数据线。

提示机型不匹配、Super 容量不足或防回滚未通过？

这些都是刷入前的保护，此时手机还没有被写入任何内容。机型不匹配请换用对应机型的刷机包；Super 容量不足时可以用“Super 扩容”（会清空数据）；防回滚未通过说明刷机包版本比手机低，刷进去会无法开机，请换更新的刷机包。

刷完一直停在开机画面？

刷完后第一次开机需要几分钟，停在开机画面是正常的，先耐心等 10 分钟左右。如果用的是“保留数据更新”并且一直进不去系统，请改用“完整线刷”（会清空数据）。仍然不行就把日志发给作者。

会锁 Bootloader 吗？刷完能退回官方系统吗？

不会，工具会拒绝执行任何锁定 Bootloader 的命令，包括官方包里的 flash_all_lock。想回到官方系统，选择小米官方线刷包，用“完整线刷”刷入即可。
